# Introduction to SQL

## Main Idea

**SQL** is a key tool Data Analysts use to work with databases, especially large datasets.

SQL is useful because it can process huge amounts of data much faster than tools like spreadsheets.

---

# 1. What Is SQL?

**SQL** stands for:

```text
Structured Query Language
```

SQL is a language analysts use to communicate with databases.

It allows analysts to:

- retrieve data
- filter data
- sort data
- clean data
- process data
- analyze large datasets
- work with relational databases

---

# 2. Why Data Analysts Use SQL

Data Analysts often use SQL because it can handle very large datasets.

SQL is especially useful when working with data that is too large for spreadsheets.

Examples of large datasets include:

- millions of rows
- billions of rows
- trillions of rows

---

# 3. SQL vs Spreadsheets

Spreadsheets are useful for smaller datasets and quick analysis.

SQL is better for larger datasets because it can process huge amounts of information quickly.

| Tool | Best Used For |
|---|---|
| Spreadsheets | Smaller datasets, simple cleaning, quick calculations, manual review |
| SQL | Large datasets, databases, complex queries, fast processing |

---

# 4. Example: Processing Huge Data

Imagine a dataset containing the names of all 8 billion people in the world.

It would take a person many years to read all those names manually.

SQL can process extremely large datasets like this in seconds.

## Key Lesson

SQL is powerful because it can handle large-scale data efficiently.

---

# 5. Relational Databases Review

SQL is commonly used with **relational databases**.

A **relational database** is a database that contains multiple tables that can be connected through relationships.

These relationships are usually created using shared fields, such as IDs.

---

# 6. Why Relational Databases Matter

Relational databases help organize data into connected tables.

For example, a business database might have separate tables for:

- customers
- orders
- products
- payments
- locations

SQL can query these tables and bring together the information needed for analysis.

---

# 7. Brief History of SQL

SQL development began in the early 1970s.

In 1970, **Edgar F. Codd** developed the theory behind relational databases.

At the time, IBM was working with a relational database management system called:

```text
System R
```

IBM computer scientists needed a way to retrieve and manipulate data from System R.

Their first query language was difficult to use, so they developed SQL.

---

# 8. SQL Becomes a Standard

SQL was publicly released in 1979.

By 1986, SQL became the standard language for relational database communication.

It is still widely used today.

---

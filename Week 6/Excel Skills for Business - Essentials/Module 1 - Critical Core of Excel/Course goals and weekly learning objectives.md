# Excel Course Goals and Weekly Learning Objectives

## Main Idea

This course is designed to build foundational Excel skills step by step.

The course moves from basic navigation and data entry to calculations, formatting, data management, printing, and charts.

---

# Course Structure

The course is organized into 6 weeks:

1. Taking Charge of Excel
2. Performing Calculations
3. Formatting
4. Working with Data
5. Printing
6. Charts

---

# Week 1: Taking Charge of Excel

## Main Focus

Week 1 introduces the Excel workspace and basic controls.

## Learning Objectives

By the end of Week 1, you should be able to:

- describe key components of the Excel user interface
- operate essential navigational controls
- perform basic data entry in Excel
- explain basic Excel terminology

---

# Week 1 Key Skills

You will learn how to:

- move around a spreadsheet
- recognize parts of the Excel interface
- enter data into cells
- understand basic terms like workbook, worksheet, cell, row, and column

---

# Week 2: Performing Calculations

## Main Focus

Week 2 focuses on formulas and functions.

## Learning Objectives

By the end of Week 2, you should be able to:

- explain the syntax of basic formulas and functions
- use formulas and functions to perform simple calculations
- describe the difference between relative and absolute cell references

---

# Week 2 Key Skills

You will learn how to:

- write basic formulas
- use simple functions
- calculate values in cells
- understand how cell references work
- use relative and absolute references correctly

---

# Week 3: Formatting

## Main Focus

Week 3 focuses on making spreadsheets clearer, more readable, and better organized through formatting.

## Learning Objectives

By the end of Week 3, you should be able to:

- give examples of key formatting tools and their uses in Excel
- modify spreadsheets with Excel styles and themes
- explain the use of number formatting in Excel
- format a raw dataset using Excel formatting tools

---

# Week 3 Key Skills

You will learn how to:

- format cells
- apply styles and themes
- change number formats
- improve readability
- make raw data easier to understand

---

# Week 4: Working with Data

## Main Focus

Week 4 focuses on managing spreadsheet data and using conditional formatting.

## Learning Objectives

By the end of Week 4, you should be able to:

- manage rows, columns, and worksheets
- identify, retrieve, and change data in spreadsheets
- explain how to operate Conditional Formatting in Excel
- use Conditional Formatting to highlight specific data

---

# Week 4 Key Skills

You will learn how to:

- insert, delete, and adjust rows and columns
- work with multiple worksheets
- find and update spreadsheet data
- apply Conditional Formatting rules
- highlight important values automatically

---

# Week 5: Printing

## Main Focus

Week 5 focuses on preparing spreadsheets for printing.

## Learning Objectives

By the end of Week 5, you should be able to:

- identify key printing tools and options in Excel
- optimize a spreadsheet for printing
- create a spreadsheet for printing with repeating elements

---

# Week 5 Key Skills

You will learn how to:

- prepare sheets for print
- adjust print settings
- manage page layout
- repeat headers or important elements
- make printed spreadsheets easier to read

---

# Week 6: Charts

## Main Focus

Week 6 focuses on creating and modifying charts in Excel.

## Learning Objectives

By the end of Week 6, you should be able to:

- describe basic chart types in Excel
- produce basic charts in Excel
- modify charts in Excel

---

# Week 6 Key Skills

You will learn how to:

- choose appropriate chart types
- create basic charts
- edit chart elements
- improve chart readability
- use charts to communicate data visually

---

---

# Big Lesson

This course builds Excel skills in a logical order.

First, you learn how to use the Excel interface and enter data. Then you learn calculations, formatting, data management, printing, and charts.

---

# Key Takeaways

- Week 1 focuses on Excel basics, navigation, data entry, and terminology.
- Week 2 focuses on formulas, functions, and cell references.
- Week 3 focuses on formatting spreadsheets and raw datasets.
- Week 4 focuses on managing data, worksheets, and Conditional Formatting.
- Week 5 focuses on preparing spreadsheets for printing.
- Week 6 focuses on creating and modifying charts.
- The course gradually moves from basic Excel use to presenting and visualizing data.

---

# Final Summary

This Excel course is organized into six weeks. Week 1 introduces the Excel interface, navigation, data entry, and terminology. Week 2 teaches formulas, functions, and relative versus absolute cell references. Week 3 focuses on formatting tools, styles, themes, number formatting, and formatting raw datasets. Week 4 covers managing rows, columns, worksheets, retrieving and changing data, and using Conditional Formatting. Week 5 explains Excel printing tools and how to optimize spreadsheets for printing. Week 6 introduces basic chart types, chart creation, and chart modification. The main goal is to build practical Excel skills for organizing, calculating, formatting, managing, printing, and visualizing data.

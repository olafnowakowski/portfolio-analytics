# Course 3, Module 1: Terms and Definitions

## Main Topic

This section reviews important vocabulary from **Course 3, Module 1**.

The terms focus on:

- data generation
- data collection
- data formats
- data types
- structured and unstructured data
- data tables
- data ethics
- data modeling

---

# Data Organization Terms

## Agenda

An **agenda** is a list of scheduled appointments.

### Example

A calendar agenda may show meetings, deadlines, and events in order by date and time.

---

## Data Element

A **data element** is a single piece of information in a dataset.

### Example

In a customer dataset, a customer’s email address is one data element.

---

## Data Model

A **data model** is a tool for organizing data elements and showing how they relate to one another.

### Why It Matters

Data models help people understand how data is structured across a system or organization.

---

# Data Table Terms

## Field

A **field** is a single piece of information from a row or column of a spreadsheet.

In a data table, a field is typically a column.

### Example

In a customer table, fields might include:

- customer name
- email address
- phone number
- city

---

## Record

A **record** is a collection of related data in a data table.

It is usually the same as a row.

### Example

In a customer table, one customer’s full row of information is one record.

---

# Data Collection Terms

## First-Party Data

**First-party data** is data collected by an individual or group using their own resources.

### Example

A company collecting customer survey responses directly from its customers.

---

## Second-Party Data

**Second-party data** is data collected by a group directly from its audience and then sold or shared.

### Example

A research company collects traffic data and sells it to another organization.

---

## External Data

**External data** is data that lives and is generated outside of an organization.

### Example

National wage statistics used by a company to compare salaries.

---

## Population

In data analytics, a **population** is all possible data values in a dataset.

### Example

If you are studying all customers of a company, the population is every customer in that company’s customer database.

---

## Sample

A **sample** is a segment of a population that represents the entire population.

### Example

Instead of surveying every customer, a company may survey 1,000 customers as a sample.

---

# Data Format Terms

## Structured Data

**Structured data** is data organized in a specific format, such as rows and columns.

### Examples

- spreadsheets
- SQL tables
- customer records
- transaction history

---

## Unstructured Data

**Unstructured data** is data that is not organized in an easily identifiable way.

### Examples

- emails
- videos
- images
- social media posts
- audio files

---

## Long Data

**Long data** is a dataset where each row is one time point per subject.

This means each subject can have data in multiple rows.

### Example

A stock price dataset where each row contains one company’s stock price for one date.

---

## Wide Data

**Wide data** is a dataset where each subject has a single row with multiple columns holding different values or attributes.

### Example

A stock price dataset where each row is one date and each company has its own column.

---

# Data Type Terms

## Boolean Data

**Boolean data** is a data type with only two possible values.

Usually, those values are:

- true
- false

### Example

A field showing whether a customer is subscribed:

- TRUE
- FALSE

---

## Continuous Data

**Continuous data** is data that is measured and can have almost any numeric value.

### Examples

- temperature
- height
- time
- distance

---

## Discrete Data

**Discrete data** is data that is counted and has a limited number of values.

### Examples

- number of tickets sold
- number of hospital visitors
- room capacity

---

## Nominal Data

**Nominal data** is a type of qualitative data that is categorized without a set order.

### Examples

- customer type
- product category
- applicant type

---

## Ordinal Data

**Ordinal data** is qualitative data with a set order or scale.

### Examples

- satisfaction level: satisfied, neutral, dissatisfied
- movie rating: 1 star, 2 stars, 3 stars
- rankings: 1st, 2nd, 3rd

---

## Text Data Type

A **text data type** is a sequence of characters and punctuation that contains textual information.

It is also called a **string data type**.

### Examples

- names
- addresses
- product descriptions
- email addresses

---

## String Data Type

A **string data type** is a sequence of characters and punctuation that contains textual information.

It is the same as a **text data type**.

---

# Digital Media Terms

## Audio File

An **audio file** is digitized audio storage, usually stored in a compressed format.

### Common Formats

- MP3
- AAC

---

## Digital Photo

A **digital photo** is an electronic or computer-based image.

### Common Formats

- BMP
- JPG

---

## Pixel

In digital imaging, a **pixel** is a small area of illumination on a display screen.

Many pixels combine together to form a digital image.

---

## Video File

A **video file** is a collection of images, audio files, and other data.

Video files are usually encoded in compressed formats.

### Common Formats

- MP4
- MV4
- MOV
- AVI
- FLV

---

# Online Data Terms

## Cookie

A **cookie** is a small file stored on a computer that contains information about its users.

### Example

Cookies can help websites remember user preferences or browsing activity.

---

## Social Media

**Social media** refers to websites and applications where users create and share content or participate in social networking.

### Examples

- social networking platforms
- content-sharing apps
- discussion platforms

---

# Data Ethics Term

## Ownership

**Ownership** is the aspect of data ethics that assumes individuals own the raw data they provide.

It also means individuals should have primary control over how their data is:

- used
- processed
- shared

### Important Lesson

Data ownership is important because people should have control over the data they provide.

---

# Organization Term

## United States Census Bureau

The **United States Census Bureau** is an agency in the U.S. Department of Commerce.

It is the nation’s leading provider of quality data about:

- people
- economy

### Why It Matters

Census data is often used for research, planning, funding decisions, and analysis.

# Big Lesson

These terms help describe how data is collected, organized, stored, structured, and used.

Understanding them helps Data Analysts prepare data correctly and choose the right data for analysis.

# Key Takeaways

- Data can be structured or unstructured.
- Structured data is organized in rows and columns.
- Unstructured data includes formats like videos, audio, emails, and social media posts.
- A record is usually a row in a data table.
- A field is usually a column in a data table.
- A data element is one piece of information in a dataset.
- First-party data is collected using your own resources.
- Second-party data is collected directly by another group and sold.
- External data is generated outside an organization.
- A population includes all possible data values in a dataset.
- A sample is a representative part of a population.
- Boolean data has only two possible values.
- Continuous data is measured.
- Discrete data is counted.
- Nominal data has no set order.
- Ordinal data has a set order.
- Long data stores each subject across multiple rows.
- Wide data stores each subject in one row with multiple columns.
- Data ownership is an important part of data ethics.
- Data models help organize data elements and relationships.

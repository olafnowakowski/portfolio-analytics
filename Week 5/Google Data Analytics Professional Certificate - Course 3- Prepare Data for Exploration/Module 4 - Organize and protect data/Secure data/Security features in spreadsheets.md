# Spreadsheet Data Security

## Main Idea

After data is organized and easy to find, it must be protected.

Spreadsheet programs such as Google Sheets and Microsoft Excel include built-in security features that help protect data from unauthorized access, accidental edits, and corruption.

---

# What Is Data Security?

## Definition

**Data security** means protecting data from unauthorized access or corruption by adopting safety measures.

---

# Why Data Security Matters

Data security helps protect data from:

- unauthorized users
- accidental edits
- broken formulas
- corrupted files
- inappropriate access
- unwanted changes

---

# Security Is Not Only About Other People

Security features do not only protect data from unauthorized users.

They can also protect data from accidental mistakes.

### Example

A worksheet can be locked so that a formula is not accidentally changed or broken.

---

# Spreadsheet Security Features

Common spreadsheet security features include:

1. **Sheet protection**
2. **Cell protection**
3. **Access control**
4. **Password protection**
5. **User permissions**
6. **Hidden tabs**
7. **Copying files for safe use**

---

# 1. Sheet Protection

## Meaning

Sheet protection prevents users from editing an entire worksheet or specific parts of a worksheet.

---

## Why It Helps

Sheet protection helps prevent accidental changes to important data, formulas, or formatting.

---

# 2. Cell Protection

## Meaning

Cell protection allows users to lock specific cells in a spreadsheet.

---

## Example

A Data Analyst may lock formula cells so collaborators do not accidentally change them.

---

# 3. Access Control

## Meaning

Access control lets the file owner decide who can view, edit, or share a spreadsheet.

---

## Why It Helps

Access control gives more control over who can do what with the data.

---

# Google Sheets Access Control

In Google Sheets, access control is managed through the **sharing menu**.

The sharing menu allows users to control:

- who can view the sheet
- who can edit the sheet
- who can comment
- who can share access with others

---

# Excel Access Control

In Excel, users can protect files and worksheets with passwords.

Excel files can also be encrypted before being emailed or shared.

---

# Password Protection

## Meaning

Password protection limits access to a spreadsheet or worksheet.

Users may need a password to open, edit, or modify the file.

---

# User Permissions

## Meaning

User permissions define what each person is allowed to do with a spreadsheet.

Examples:

- view only
- comment only
- edit access
- owner access

---

# Google Sheets Copying Feature

Google Sheets can be copied so users can work with the data without changing the original file.

This helps protect the original dataset.

---

# Hidden Tabs

Both Google Sheets and Excel allow users to hide and unhide tabs.

---

## Why Hide Tabs?

Hiding tabs can help control what data is visible during normal use.

---

## Important Warning

Hidden tabs are not fully secure.

Someone with enough access may be able to unhide them.

### Important Lesson

Do not rely on hidden tabs to protect sensitive data.

---

# Google Sheets vs Excel Security

| Feature | Google Sheets | Excel |
|---|---|---|
| Sheet protection | Yes | Yes |
| Cell protection | Yes | Yes |
| Access control | Sharing menu and permissions | File and worksheet permissions |
| Password protection | Managed mostly through account/share settings | Password encryption available |
| Copying files | Easy to copy online | Files can be duplicated |
| Hidden tabs | Available | Available |

---

# Collaboration and Security

When multiple people work on the same spreadsheet, security features are especially important.

They help prevent:

- accidental formula changes
- unauthorized edits
- confusion over file versions
- damage to important calculations

---

# Locking Formulas

Locking formulas is useful when collaborating.

It allows others to view or use the spreadsheet without accidentally breaking important calculations.

---

# Why Data Analysts Need Security

Data Analysts often work with important or sensitive information.

Protecting spreadsheets helps keep analysis:

- accurate
- reliable
- secure
- usable
- trustworthy

---

# Data Preparation Includes Security

Preparing data does not only mean organizing it.

It also means securing it.

Before moving further in the data analysis lifecycle, analysts should make sure data is:

- organized
- easy to find
- protected
- secure
- ready to use

# Key Takeaways

- Data security means protecting data from unauthorized access or corruption.
- Spreadsheet programs have built-in security features.
- Google Sheets and Excel both allow users to protect sheets, cells, and files.
- Sheet protection can prevent accidental edits.
- Cell protection can protect formulas.
- Access control lets users decide who can view or edit a spreadsheet.
- Excel allows password protection and file encryption.
- Google Sheets uses sharing settings and permissions.
- Google Sheets files can be copied so users do not change the original.
- Hidden tabs can still be unhidden by users with access.
- Hidden tabs should not be treated as strong security.
- Data Analysts should make data security a priority.
- Data preparation includes both organizing and protecting data.

---

# Extra Important Notes

- Security features can protect against both people and mistakes.
- Locking formulas is useful in shared spreadsheets.
- Permissions should match the user’s role.
- Avoid giving edit access to people who only need to view data.
- Hidden tabs are useful for presentation, but not for true protection.
- Always think about who can access sensitive data.
- Organized and secure data is easier to trust and use.

# Final Summary

This lesson explains how spreadsheet security features help protect data. Data security means protecting data from unauthorized access or corruption by using safety measures. Spreadsheet programs such as Google Sheets and Excel include features like sheet protection, cell protection, access control, password protection, user permissions, hidden tabs, and file copying. These features can prevent unauthorized users from viewing data and can also stop collaborators from accidentally breaking formulas or changing important information. Excel supports password encryption, while Google Sheets uses sharing settings to control who can view or edit a file. Hidden tabs can be useful, but they are not fully secure because users with access may unhide them. The main lesson is that data preparation includes both organizing and securing data before analysis begins.

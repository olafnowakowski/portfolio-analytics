### Fill in the blank: Data security involves adopting _____ in order to protect data from unauthorized access or corruption. 
- safety measures
> Data security involves adopting safety measures in order to protect data from unauthorized access or corruption. 

---

### What data-security measure uses a unique algorithm to alter data and make it inaccessible without the algorithm?
- Encryption
> Encryption uses a unique algorithm to alter data and make it inaccessible without the algorithm. 

---

### When using tokenization as a safety measure, what is replaced as a randomly generated token?
- The data elements to be protected
> When using tokenization as a safety measure, the data elements to be protected are replaced as a randomly generated token.

---

### What data-security practice enables all collaborators within a file to track changes, such as who made what edits to the file, when they were made, and why?
- Version control
> Version control enables all collaborators within a file to track changes, such as who made what edits to the file, when they were made, and why.

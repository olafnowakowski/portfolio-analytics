# Metadata

## Main Idea

**Metadata** is data about data.

It gives context about data so analysts can understand what the data means, where it came from, how it was created, and how it should be used.

---

# What Is Metadata?

## Definition

**Metadata** is information used to describe the data contained in something.

Metadata is not the data itself.

Instead, it is **data about the data**.

---

# Why Metadata Matters

Metadata helps Data Analysts understand and interpret data.

Without metadata, data may lack context.

Metadata can explain:

- what the data is about
- where the data came from
- when the data was created
- how the data was created
- what format the data is in
- how the data is organized
- how the data should be interpreted

---

# Metadata as a Guide

Metadata works like a guide or description.

It helps analysts understand the meaning of data before using it for analysis.

### Important Lesson

Data without metadata can be confusing because there may be no clear explanation of what the data represents.

---

# Everyday Example: Photo Metadata

When a photo is taken with a smartphone, metadata is automatically stored with the photo.

Photo metadata may include:

- file type
- date taken
- time taken
- geolocation
- device used
- camera settings
- file size

---

# Photo Metadata Example

If you right-click a photo and choose **Get Info** or **Properties**, you may see metadata about the photo.

This information describes the photo file, but it is not the photo itself.

---

# Everyday Example: Email Metadata

Emails also contain metadata.

You can usually find it by selecting options such as:

- Show Original
- View Message Details

---

# Email Metadata May Include

An email’s metadata may include:

- subject
- sender
- recipient
- date sent
- time sent
- delivery time
- message path

---

# Metadata vs Data

| Concept | Meaning |
|---|---|
| **Data** | The actual information or content |
| **Metadata** | Information that describes the data |

---

# Example: Photo

| Type | Example |
|---|---|
| **Data** | The actual image of the dogs |
| **Metadata** | File type, date taken, device used, location |

---

# Example: Email

| Type | Example |
|---|---|
| **Data** | The message written in the email |
| **Metadata** | Sender, receiver, subject, time sent |

---

# Metadata in Data Analytics

In data analytics, metadata helps analysts interpret the contents of data within a database.

It helps answer questions like:

- What does this field mean?
- Where did this data come from?
- When was this data collected?
- How was this data created?
- What format is this data in?
- Can this data be trusted?
- How should this data be used?

---

# Why Metadata Is Important for Databases

Metadata is important in database management because it tells analysts what the data is about.

This helps analysts use data to:

- solve problems
- make decisions
- understand relationships
- avoid misinterpretation
- prepare data correctly

---

# Three Common Types of Metadata

Data Analysts commonly work with three types of metadata:

1. **Descriptive metadata**
2. **Structural metadata**
3. **Administrative metadata**

---

# 1. Descriptive Metadata

## Definition

**Descriptive metadata** is metadata that describes a piece of data and can be used to identify it later.

---

## Example: Library Book

For a book in a library, descriptive metadata may include:

- title
- author
- ISBN

---

## ISBN

An **ISBN**, or International Standard Book Number, is a unique code used to identify a book.

It is often found on the spine or back cover of a book.

---

## Purpose of Descriptive Metadata

Descriptive metadata helps people find and identify data.

### Important Lesson

Descriptive metadata answers: **What is this data?**

---

# 2. Structural Metadata

## Definition

**Structural metadata** indicates how a piece of data is organized and whether it is part of one or more data collections.

---

## Example: Book Chapters

For a book, structural metadata could describe how pages are organized into chapters.

---

## Relationship Tracking

Structural metadata can also track relationships between things.

### Example

Structural metadata can show that a digital manuscript was the original version of a printed book.

---

## Purpose of Structural Metadata

Structural metadata helps explain how data is arranged and connected.

### Important Lesson

Structural metadata answers: **How is this data organized?**

---

# 3. Administrative Metadata

## Definition

**Administrative metadata** indicates the technical source and details of a digital asset.

---

## Example: Photo Metadata

The metadata inside a photo is often administrative metadata.

It may show:

- file type
- date taken
- time taken
- device used
- file size
- location

---

## Purpose of Administrative Metadata

Administrative metadata helps manage and understand technical information about a data asset.

### Important Lesson

Administrative metadata answers: **How was this data created or managed?**

---

# Metadata Types Summary

| Metadata Type | Meaning | Example |
|---|---|---|
| **Descriptive metadata** | Identifies and describes data | Book title, author, ISBN |
| **Structural metadata** | Shows how data is organized or connected | Book pages grouped into chapters |
| **Administrative metadata** | Shows technical details about a digital asset | Photo file type, date, device used |

---

# Library Book Example

Before reading a book, you can look up metadata such as:

- title
- author
- length
- number of chapters
- ISBN

This metadata tells you information about the book.

But to fully understand the book, you still need to read it.

---

# Important Comparison

Metadata can tell you a lot about data, but it does not replace the data itself.

### Example

A book’s metadata can tell you the title and author, but not the full story.

A dataset’s metadata can tell you where the data came from, but not the full analysis result.

# Final Summary

Metadata is data about data. It describes information contained in something, such as a photo, email, book, or database. Photo metadata may include the file type, date and time taken, geolocation, and device used. Email metadata may include the subject, sender, recipient, and time sent. In data analytics, metadata helps analysts understand and interpret database contents. There are three common types of metadata: descriptive, structural, and administrative. Descriptive metadata identifies data, such as a book’s title, author, or ISBN. Structural metadata shows how data is organized, such as pages arranged into chapters. Administrative metadata provides technical details, such as file type or creation date. The main lesson is that metadata gives context, helping analysts understand what data means and how to use it correctly.

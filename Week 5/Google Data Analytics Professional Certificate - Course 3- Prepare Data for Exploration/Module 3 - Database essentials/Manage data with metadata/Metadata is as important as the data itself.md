# Metadata

## Main Idea

**Metadata** is data about data.

It helps Data Analysts understand the content, context, structure, origin, and usefulness of data.

---

# What Is Metadata?

## Definition

**Metadata** is information that describes other data.

In database management, metadata helps Data Analysts interpret the contents of data within a database.

---

# Simple Explanation

Metadata tells you important details about a file, document, dataset, photo, email, website, book, or other item.

It helps answer questions such as:

- What is this data?
- Where did it come from?
- Who created it?
- When was it created?
- Who changed it?
- Who can access it?
- What does it contain?
- How is it organized?

---

# Why Metadata Matters

Metadata is important because it gives data context.

Without metadata, analysts may have data but not understand what it means or how to use it correctly.

---

# Metadata Helps Analysts

Metadata helps Data Analysts:

- understand data content
- understand data context
- interpret database contents
- communicate about data
- reuse data
- find data later
- preserve data
- manage data accurately
- understand how data is structured

---

# Metadata and Analytics Teams

Metadata is a sign of a knowledgeable analytics team.

It helps people across a business communicate about data more clearly.

It also makes data easier to reuse in future projects.

---

# Metadata Answers Key Questions

Metadata tells the:

- who
- what
- when
- where
- which
- why
- how

of data.

---

# Elements of Metadata

Metadata can include many different kinds of information.

Common metadata elements include:

1. File or document type
2. Date, time, and creator
3. Title and description
4. Geolocation
5. Tags and categories
6. Last modified information
7. Access and update permissions

---

# 1. File or Document Type

Metadata can tell you what type of file or document you are examining.

Examples:

- photo
- spreadsheet
- email
- document
- website
- audio file
- book
- dataset

---

# 2. Date, Time, and Creator

Metadata can show:

- when the item was created
- who created it
- when it was last modified

This helps analysts understand the history of the data.

---

# 3. Title and Description

Metadata can provide the name of the item and explain what content it contains.

Examples:

- document title
- spreadsheet title
- website title
- file description
- dataset description

---

# 4. Geolocation

For photos or location-based data, metadata can show where the item was created.

Example:

A smartphone photo may include the location where the photo was taken.

---

# 5. Tags and Categories

Metadata can include tags or categories that summarize or classify the item.

This helps with:

- searching
- filtering
- indexing
- organizing
- describing content

---

# 6. Last Modified Information

Metadata can show whether changes were made to a file.

It can also show:

- who last modified it
- when it was last modified

---

# 7. Access and Update Permissions

Metadata can show who can access or update a file or dataset.

It may answer questions such as:

- Is the dataset public?
- Are special permissions needed?
- Who can edit the file?
- Who can modify the dataset?

---

# Examples of Metadata

Metadata appears in many places, including:

- photos
- emails
- spreadsheets
- electronically created documents
- websites
- books
- audiobooks

---

# Photo Metadata

When a photo is taken with a camera or smartphone, metadata is saved with it.

Photo metadata can include:

- filename
- date taken
- time taken
- geolocation
- device used
- image size
- description

---

# Email Metadata

Emails contain metadata.

Visible email metadata can include:

- subject line
- sender
- recipient
- date sent
- time sent

---

# Hidden Email Metadata

Emails can also include hidden metadata.

Hidden email metadata may include:

- server names
- IP addresses
- HTML format
- software details
- message ID
- creation date
- SPF
- DKIM
- DMARC

---

# Spreadsheet Metadata

Spreadsheets contain both data and metadata.

Spreadsheet metadata can include:

- title
- author
- creation date
- owner
- file type
- file size
- storage used
- last modified information
- last opened information
- download permissions
- description
- tab names
- tables
- columns

---

# Document Metadata

Electronically created documents can include metadata such as:

- title
- author
- creation date
- number of pages
- comments
- last modified information
- access permissions

---

# Website Metadata

Web pages contain metadata.

Website metadata can include:

- tags
- categories
- site creator name
- web page title
- web page description
- time of creation

---

# Search Engine Results and Metadata

Search engine results are examples of metadata.

A search result often shows:

- page title
- website link
- meta description

This metadata helps users decide whether a result is relevant.

---

# Book Metadata

Non-digital items can also have metadata.

A book’s metadata can include:

- title
- author
- table of contents
- publisher information
- copyright description
- index
- brief description of contents

---

# Audiobook Metadata

Audiobooks include book-related metadata plus audio-specific metadata.

Audiobook metadata can include:

- title
- author
- narrator
- recording length
- release date
- language
- publisher
- rating score

---

# Metadata in Daily Life

People use metadata every day to stay organized.

Examples:

- searching for an email by sender or date
- finding a photo by location or time
- choosing a website result from a search engine
- locating a book by title or author
- checking who last edited a spreadsheet

# Final Summary

Metadata is data about data. It provides important context that helps Data Analysts understand what data is, where it came from, who created it, when it was created, how it is structured, and who can access or update it. Metadata appears in many places, including photos, emails, spreadsheets, documents, websites, books, and audiobooks. Photo metadata may include file type, date, time, location, and device used. Metadata helps analysts communicate about data, reuse data, preserve data, and manage data responsibly. The main lesson is that metadata is as important as the data itself because it gives data meaning, context, and structure.

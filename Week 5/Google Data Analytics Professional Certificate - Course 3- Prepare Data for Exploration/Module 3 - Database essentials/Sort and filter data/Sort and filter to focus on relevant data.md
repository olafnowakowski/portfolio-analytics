# Sorting and Filtering Data

## Main Idea

Sorting and filtering help Data Analysts focus on the data that is most relevant to the problem they are trying to solve.

These tools are especially useful when working with large or complex spreadsheets.

---

# Why Sorting and Filtering Matter

Large spreadsheets can contain a lot of information.

This can make it difficult to quickly find and analyze the data needed for a specific project.

Sorting and filtering help analysts:

- organize data
- focus on relevant information
- customize how data is presented
- find patterns more easily
- narrow down large datasets
- prepare data for analysis

---

# Different Analysts May Use the Same Data Differently

No two analytics projects are exactly the same.

Different Data Analysts may use the same dataset in different ways depending on the question they are trying to answer.

### Example

A spreadsheet may show:

- sales reps
- cities
- states
- products they work with

One analyst may want to organize sales reps by city.

Another analyst may want to filter for only one product.

---

# Sorting

## Definition

**Sorting** means arranging data into a meaningful order to make it easier to understand, analyze, and visualize.

---

# Ways to Sort Data

Data can be sorted:

- alphabetically
- numerically
- in ascending order
- in descending order
- by one column
- by multiple columns
- across a full spreadsheet
- within a single column or table

---

# Ascending Order

**Ascending order** arranges values from smallest to largest or A to Z.

### Examples

- A to Z
- 1 to 100
- oldest to newest

---

# Descending Order

**Descending order** arranges values from largest to smallest or Z to A.

### Examples

- Z to A
- 100 to 1
- newest to oldest

---

# Sorting by One Column

You can sort a spreadsheet using one selected column as the main sorting criteria.

### Example

If you sort by **City** from A to Z, the cities will be arranged alphabetically.

The other columns in each row stay connected to their original records.

---

# Keeping Rows Together

When sorting a full spreadsheet, the details across each row are kept together.

This means the sales rep, state, city, and product information remain correctly connected.

### Important Lesson

When sorting, make sure the whole dataset is included so rows do not become mismatched.

---

# Freeze the Header Row

Before sorting, it is a good idea to freeze the header row.

## Why Freeze the Header Row?

Freezing the header row keeps column names visible when scrolling.

This helps analysts remember what each column represents.

---

# How to Freeze the Header Row

## Steps

1. Highlight the header row.
2. Go to the **View** menu.
3. Choose **Freeze**.
4. Select **1 row**.

Now the header row stays visible when scrolling down the sheet.

---

# Multiple Criteria Sorting

## Definition

**Multiple criteria sorting** means sorting data by more than one variable.

---

# Example: Sort by State, Then City

Suppose you want to see sales reps by the states and cities where they work.

You can sort first by **State**, then by **City**.

---

## Steps for Multiple Criteria Sorting

1. Select the entire dataset.
2. Choose **Data**.
3. Select **Sort range**.
4. Make sure **Data has header row** is selected.
5. Choose the first sort column, such as **State**.
6. Select the order, such as A to Z.
7. Add another sort column.
8. Choose the second sort column, such as **City**.
9. Select the order, such as A to Z.
10. Select **Sort**.

---

# Why “Data Has Header Row” Matters

Selecting **Data has header row** prevents the column labels from being included in the sort.

This keeps headers such as:

- City
- State
- Sales Rep
- Auto Parts

at the top of the dataset.

---

# When Sorting Is Useful

Sorting is useful when you want to view the whole spreadsheet in a meaningful order.

Examples:

- customers alphabetically by name
- sales from highest to lowest
- dates from oldest to newest
- cities from A to Z
- employees grouped by department
- products sorted by price

---

# Filtering

## Definition

**Filtering** means showing only the data that meets specific criteria while hiding the rest.

---

# Why Filtering Matters

Filtering simplifies a spreadsheet by showing only the information needed for the analysis.

It helps analysts isolate specific information.

---

# Filtering vs Sorting

| Tool | What It Does |
|---|---|
| **Sorting** | Arranges data in a meaningful order |
| **Filtering** | Shows only data that meets selected criteria |

---

# Example: Filtering by Product

Suppose you want to see only the sales reps who worked with a particular auto part.

You can filter the **Auto Parts** column.

---

# How to Create a Filter

## Steps

1. Select **Data**.
2. Choose **Create a filter**.
3. Filter buttons will appear in the column headers.
4. Select the filter button in the column you want to filter.
5. Choose the values you want to display.
6. Select **OK**.

---

# Example: Filter for Rims

If you want to see only sales reps who worked with rims:

1. Open the filter menu in the **Auto Parts** column.
2. Remove check marks from all categories except **Rims**.
3. Select **OK**.

The spreadsheet will show only rows where the auto part is rims.

---

# What Happens to Hidden Data?

Filtering temporarily hides rows that do not meet the condition.

The hidden data is still in the spreadsheet.

It is not deleted.

---

# Turning Off a Filter

When you want to view the full spreadsheet again, turn off the filter.

This brings back the hidden rows.

---

# Sorting and Filtering as a Magnifying Glass

Sorting and filtering help analysts zoom in on the data that matters.

They act like a magnifying glass for large datasets.

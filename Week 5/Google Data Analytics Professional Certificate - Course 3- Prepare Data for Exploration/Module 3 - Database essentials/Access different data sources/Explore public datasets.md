# Resources for Open Data

## Main Idea

Open data creates many public datasets that Data Analysts can access and use to make data-driven decisions.

These datasets can support practice, research, analysis, visualization, and business decision-making.

---

# Why Public Datasets Matter

Public datasets help Data Analysts:

- practice analysis skills
- explore real-world data
- make data-driven decisions
- build dashboards
- create visualizations
- compare trends
- support research
- answer business questions

# Choosing the Right Dataset

When choosing a public dataset, ask:

- Is the dataset relevant to my question?
- Is the dataset reliable?
- Is the dataset current enough?
- Is the dataset cited?
- Is the dataset complete enough?
- Is the source credible?
- Can I download or access it easily?
- Is it available in a format I can use?
- Does it include metadata?
- Are there privacy or ethical concerns?

- Some datasets are available as CSV files.
- Metadata is important because it helps analysts understand public datasets.

- Analysts should check whether a public dataset includes personally identifiable information.
- Public data can add context to business, health, climate, and social analysis.
- Dataset choice should always depend on the analysis question.

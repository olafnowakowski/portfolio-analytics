# Importing Data From Different Sources

## Main Idea

Data Analysts often need to import data from different sources into spreadsheets so they can prepare, review, clean, analyze, and visualize it.

One common file type used for importing data is a **CSV file**.

---

# What Is a CSV File?

## Definition

**CSV** stands for **comma-separated values**.

A CSV file stores data in a table format using plain text.

---

# CSV File Structure

CSV files organize data into:

- rows
- columns
- fields

Each value is separated by a comma.

---

# Why CSV Files Are Useful

CSV files are useful because:

- they store data in a simple table format
- they use plain text
- they are easy to import into spreadsheets
- they are easy to transfer between tools
- they are commonly used in data analysis

---

# Importing a CSV Into a Spreadsheet

## Basic Steps

To import a CSV file into a spreadsheet:

1. Open a fresh spreadsheet.
2. Select **File**.
3. Select **Import**.
4. Choose **Upload**.
5. Select the CSV file from your device.
6. Open the file.
7. Insert it as a new sheet.
8. Select **Import data**.

---

# Why Separators Matter

CSV files are separated by characters.

Usually, the separator is a comma.

The spreadsheet app will often auto-detect the comma separations.

---

# Other Possible Separators

Sometimes, the separator may not be a comma.

It could be:

- a space
- a tab
- another character

If the spreadsheet does not detect the separator correctly, you may need to select the correct separator option manually.

---

# Data Type Conversion During Import

When importing data, spreadsheet tools may allow you to convert values into:

- text
- numbers
- dates
- other formats

---

## When Plain Text Is Okay

If the data is being used mainly for reporting purposes, leaving the values as plain text may be acceptable.

If the data will be analyzed mathematically, you may need to make sure numeric fields are treated as numbers.

---

# After Importing the CSV

Once the CSV is imported, the data is ready to work with in the spreadsheet.

You can then:

- review the data
- clean the data
- sort the data
- filter the data
- analyze the data
- create charts
- generate reports

---

# Working With Large Datasets

Data Analysts often begin with a larger dataset.

Then they pull a smaller subset of the data into a spreadsheet to work with.

---

## Why Use a Subset?

A subset can make the data easier to:

- inspect
- analyze
- summarize
- report
- visualize

# Downloading Data From a Website

## Basic Steps

To download data from a website as a CSV file:

1. Find the webpage containing the dataset.
2. Choose the option to download the data.
3. Select CSV format.
4. Save the file to your device.

---

# Importing Downloaded Data Into a Spreadsheet

## Steps

After downloading the CSV file:

1. Open a new spreadsheet.
2. Select **File**.
3. Select **Import**.
4. Upload the CSV file.
5. Select **Import Data**.
6. Review the imported data.
7. Title the spreadsheet.
8. Begin analysis.

---

# Reviewing the Data

After importing, review the data to make sure it looks clean.

Check for:

- missing values
- incorrect columns
- formatting issues
- wrong separators
- unexpected symbols
- incorrect data types
- messy headers

---

# Why Reviewing Imported Data Matters

Imported data may not always appear correctly at first.

Reviewing helps make sure the data is usable before analysis begins.

---

# Sorting and Filtering

After importing data into a spreadsheet, analysts can sort and filter the data.

These tools help focus on the information that is most relevant.

---

## Sorting

Sorting arranges data in a specific order.

Examples:

- sort by country
- sort by year
- sort by number of doctors
- sort alphabetically
- sort from highest to lowest

---

## Filtering

Filtering shows only the data that meets selected conditions.

Examples:

- show only one country
- show only one year
- show only records above a certain value
- show only a specific healthcare indicator

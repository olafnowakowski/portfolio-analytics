# Databases and Metadata

## Main Idea

A **database** is a collection of data stored in a computer system.

Databases help Data Analysts store, find, sort, and use data for analysis.

This lesson also introduces **metadata**, which means **data about data**.

---

# What Is a Database?

## Definition

A **database** is a collection of data stored in a computer system.

Databases are useful because they do more than simply store data.

They help analysts:

- find specific information
- sort data
- organize data
- generate reports
- prepare data for analysis
- locate the exact data needed for a business question

---

# Why Databases Matter

Databases make it possible to find the exact piece of information needed for analysis.

Instead of searching through large amounts of disorganized data, analysts can use a database to access and organize information more efficiently.

### Important Lesson

Databases help Data Analysts work with large collections of data in an organized way.

---

# Sorting Data

Databases allow analysts to sort data.

Sorting helps analysts zoom in on the information they need.

Examples of sorting data:

- sorting customers by location
- sorting sales by date
- sorting products by price
- sorting employees by department
- sorting transactions by amount

---

# Databases and Reports

Databases can help analysts generate useful reports.

Reports can help answer business questions and communicate insights to stakeholders.

Examples of reports:

- monthly sales reports
- customer activity reports
- inventory reports
- financial reports
- website traffic reports

---

# Metadata

## Definition

**Metadata** is data about data.

Metadata gives context about a dataset.

---

# Metadata as a Reference Guide

Metadata is like a reference guide for data.

Without metadata, you may have data but no clear explanation of what it means.

Metadata helps explain:

- where the data came from
- when the data was created
- how the data was created
- what the data is about
- how the data should be understood
- how the data should be used

---

# Why Metadata Matters

Metadata is extremely important when working with databases.

It gives context that helps analysts understand the data correctly.

Without metadata, data may be confusing or misleading.

### Important Lesson

Metadata helps analysts understand the meaning, source, and structure of data.

---

# Examples of Metadata

Metadata might include:

- file name
- date created
- date modified
- data source
- author or creator
- column descriptions
- field names
- data type
- data format
- collection method
- update frequency
- permissions
- data owner

---

# Simple Example of Metadata

A spreadsheet may contain customer purchase data.

The metadata might tell you:

- the data came from the company’s sales system
- the file was created on March 1
- the data covers purchases from January through February
- the “Amount” column is in U.S. dollars
- the “Customer ID” field is unique for each customer

---

# Why Analysts Should Analyze Their Own Analysis

The speaker explains that analysts should sometimes step back and analyze how they analyze data.

This means checking whether their methods are:

- fair
- logical
- unbiased
- appropriate
- reliable
- aligned with the business question

---

# Quality Checking Your Work

Analyzing your analysis is a way to quality check your work.

It helps ensure that:

- your methods make sense
- your data is appropriate
- your analysis is fair
- your conclusions are reliable
- your process does not introduce bias

---

# Bias and Metadata

Metadata can help analysts identify possible bias by showing:

- where the data came from
- how it was collected
- when it was collected
- who collected it
- what the data represents
- what the data may exclude

### Important Lesson

Knowing the background of data helps analysts check whether the data is fair and useful.

---

# Getting Too Close to the Data

Sometimes analysts can get too close to their data.

This means they may become so focused on the details that they forget to question the process.

To avoid this, analysts should step back and ask:

- Does this process make sense?
- Is this data fair?
- Is this data complete?
- Could bias affect the outcome?
- Am I using the right data for the question?

---

# Importing Data

The lesson introduces the idea of taking data from a database or another source and bringing it into a spreadsheet.

This can be done by:

- importing data directly
- using SQL to request data

---

# Importing Data Directly

Importing data directly means bringing data from a database or file into a spreadsheet.

This allows analysts to work with the data using spreadsheet tools.

---

# Using SQL

**SQL** can be used to generate a request for data from a database.

SQL helps analysts ask databases for specific information.

Examples of SQL tasks:

- selecting certain columns
- filtering rows
- sorting results
- joining tables
- pulling data into another tool

---

# Databases and Spreadsheets

After data is brought into a spreadsheet, analysts can do many things with it.

Examples:

- sort data
- filter data
- clean data
- calculate values
- create charts
- summarize trends
- prepare reports

---

# Connection to the Prepare Phase

Working with databases, metadata, SQL, and spreadsheets is part of the **Prepare** phase of the data analysis process.

The Prepare phase is where analysts figure out what kind of data will be most helpful.

---

# Why the Prepare Phase Matters

If analysts choose the right data, they are more likely to solve the business problem successfully.

Preparing data well helps ensure that the data is:

- relevant
- organized
- accurate
- useful
- trustworthy
- ready for analysis

---

# Big Lesson

Databases help analysts store, find, sort, and use data.

Metadata helps analysts understand what the data means.

Together, databases and metadata help analysts prepare the right data for successful analysis.

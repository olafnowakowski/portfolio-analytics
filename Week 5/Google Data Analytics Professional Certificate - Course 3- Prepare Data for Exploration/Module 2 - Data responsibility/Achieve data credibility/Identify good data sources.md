# Identifying Good Data Sources

## Main Idea

Good data sources are important because high-quality data leads to more trustworthy analysis and better decisions.

To evaluate whether a data source is good, use the **ROCCC** framework:

- **Reliable**
- **Original**
- **Comprehensive**
- **Current**
- **Cited**

---

# Why Good Data Matters

Data Analysts need good data because the quality of the data affects the quality of the analysis.

The better the data, the more confidence you can have in:

- your findings
- your recommendations
- your decisions
- your conclusions

### Important Lesson

High-quality data supports high-quality decisions.

---

# Are Good Data Sources Subjective?

The word “good” can be subjective.

For example, one person’s idea of a good song may be different from someone else’s.

However, good data sources can be judged using best practices.

The **ROCCC** framework helps analysts measure whether a data source is reliable enough to use.

---

# ROCCC Framework

## What ROCCC Means

**ROCCC** stands for:

1. Reliable
2. Original
3. Comprehensive
4. Current
5. Cited

A good data source should meet all five standards.

---

# 1. Reliable

## Definition

A reliable data source provides information that is accurate, complete, unbiased, and fit for use.

---

## What Reliable Data Should Be

Reliable data should be:

- accurate
- complete
- unbiased
- vetted
- proven useful for the analysis

---

## Why Reliability Matters

If data is not reliable, the analysis may produce incorrect or misleading results.

### Important Lesson

Reliable data can be trusted.

---

# 2. Original

## Definition

Original data comes from the original source, not only from a second-party or third-party source.

---

## Why Original Data Matters

You may discover data through a second-party or third-party source.

However, to make sure the data is trustworthy, you should try to validate it with the original source.

---

## Example

If a website shares statistics from a government report, the original source is the government report.

The best practice is to check the original report instead of relying only on the website.

### Important Lesson

Original sources help confirm that the data is accurate and has not been changed or misinterpreted.

---

# 3. Comprehensive

## Definition

Comprehensive data contains all the critical information needed to answer the question or solve the problem.

---

## Why Comprehensiveness Matters

A dataset may be accurate but still incomplete.

If important information is missing, the analysis may not fully answer the business question.

---

## Example

You would not decide whether to work for a company based on one positive online review.

You would research multiple parts of the organization before deciding.

The same idea applies to data analysis.

### Important Lesson

Good data should include enough information to fully support the analysis.

---

# 4. Current

## Definition

Current data is up to date and relevant to the task.

---

## Why Current Data Matters

The usefulness of data often decreases over time.

Old data may no longer represent the current situation.

---

## Example

If you want to invite current clients to a business event, you should not use a client list from 10 years ago.

That list may include people who are no longer clients and may exclude newer clients.

### Important Lesson

Data should be recent enough to answer the current question.

---

# 5. Cited

## Definition

Cited data includes information about where the data came from.

A citation makes the information more credible.

---

## Why Cited Data Matters

Citations help people verify the data.

When a source is cited, you can check:

- who created the dataset
- where the data came from
- whether the source is credible
- when the data was last updated

---

# Questions to Ask About a Data Source

When choosing a data source, ask:

1. Who created the dataset?
2. Is the dataset from a credible organization?
3. When was the data last refreshed?

---

# Good Sources of Data

Some places are known for providing strong data sources.

Examples include:

- vetted public datasets
- academic papers
- financial data
- governmental agency data

---

# What Makes a Data Source Strong?

A strong data source is:

- reliable
- original
- comprehensive
- current
- cited

If a data source meets all five ROCCC standards, it is more likely to be trustworthy.

---

# ROCCC Summary Table

| ROCCC Element | Meaning | Why It Matters |
|---|---|---|
| **Reliable** | Accurate, complete, unbiased, and fit for use | Helps ensure trustworthy analysis |
| **Original** | Validated with the original source | Helps avoid copied or distorted data |
| **Comprehensive** | Contains all needed information | Helps fully answer the question |
| **Current** | Up to date and relevant | Helps reflect the present situation |
| **Cited** | Source information is provided | Helps verify credibility |

---

# Data Source Quality Checklist

Before using a dataset, check whether it is:

- accurate
- complete
- unbiased
- from the original source
- broad enough to answer the question
- up to date
- properly cited
- from a credible organization
- refreshed recently
- appropriate for the task

---

# Big Lesson

Good data sources are not chosen randomly.

Data Analysts should evaluate sources carefully before using them.

The ROCCC framework helps determine whether data is trustworthy enough for analysis.

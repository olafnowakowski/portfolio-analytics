# 13. Do-not-claim rules

These restrictions are mandatory. Do not violate them to make a job application sound stronger.

## 13.1 Technical exaggeration restrictions

Do not claim:

- advanced programming;
- professional software developer experience;
- professional Data Analyst experience yet;
- advanced Power BI experience;
- advanced SQL experience;
- advanced Python experience;
- advanced R experience;
- advanced Tableau experience;
- advanced infrastructure/system administration;
- advanced Docker experience;
- advanced Supabase/Postgres administration;
- DevOps/cloud/network engineering experience;
- SAP/ServiceNow administration unless clearly supported by a future role;
- CAPP/VMS as market-known systems.

## 13.2 Experience-label restrictions

Do not claim:

- the game tester role as formal employment if it was a beta/community role;
- personal n8n workflow as professional production infrastructure;
- senior strategic ownership beyond the operational/function scope;
- formal annual budget ownership;
- formal supplier negotiation;
- long-term department strategy ownership;
- formal senior-management decision authority;
- formal process maps/flowcharts if not actually created;
- formal FAQ/troubleshooting documentation if not actually created.

## 13.3 Jira ticket number restrictions

Safe claim:

- prepared/authored 100 Jira tickets.

Do not claim without further verification:

- directly created all 100 under own account;
- 117 tickets total;
- 98 production releases;
- 19 QA changes.

These numbers may be true from another source, but the current archive only confirms the 100-ticket portfolio and statuses as discussed.

## 13.4 AI usage restrictions

Do not imply:

- AI makes decisions independently;
- AI output is sent without review;
- AI replaces professional judgment;
- AI-generated code is used without testing.

Correct version:

> AI is used as an assistant. Outputs are manually checked, verified and adjusted before use.

## 13.5 CAPP/VMS wording restriction

Do not write only:

- “CAPP expert”
- “VMS expert”

Better:

> Advanced key user of company-specific internal operational systems used for task management, scheduling, cleaning workflows, technical requests, user administration, data configuration and process control.
